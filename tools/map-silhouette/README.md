# Силуэт области для фона сотовой карты

```
python tools/map-silhouette/make_silhouette.py
```

Читает `frontend/public/maps/kurgan-oblast-outline.svg`, пишет рядом
`kurgan-oblast-silhouette.svg`. Запускается один раз; в сборку не входит.

## Зачем понадобилось

ВКС 24.08.2026, реплика Николая Ермакова про карту: «что это за разнотона?
И какая-то полоска вертикальная под МРБ, уходящая вниз, и как будто так окно.
Плюс здесь светлее, здесь темнее».

«Окно» рисовал сам файл контура. `kurgan-oblast-outline.svg` — карта
с Викисклада, и первым элементом в ней лежит

```xml
<rect id="rect6689" width="1000" height="736" style="fill:#f5f5f5" />
```

На тёмной карте контур выводился через `filter: invert(1) saturate(0)
brightness(1.35)`, и этот почти белый прямоугольник становился тёмно-серым.
Дальше геометрия: исходный viewBox 1000×736 (соотношение 1,36) вписывался
в `<image>` 740×460 (1,61) с `preserveAspectRatio="xMidYMid meet"`, то есть
подгонялся по высоте и занимал 625×460 по центру. Его вертикальные края
и были той самой «полоской, уходящей вниз», а сам прямоугольник — «окном».

## Что делает сценарий

Берёт из исходника только группу `g6632` — районы Курганской области — и кладёт
её в новый файл с тем же `viewBox`, одной группой со сплошной белой заливкой.
Не переносит ничего лишнего: фоновый прямоугольник, соседние регионы (`#e0e0e0`),
реки и дороги (`polyline2523`, `path2375`) остаются в исходнике.

**ViewBox сохраняется намеренно** — `61.7 54 1000 736`. Благодаря этому силуэт
встаёт в `<image>` ровно там же, где стоял контур, и соты относительно него
не смещаются: правка чисто визуальная, координаты МО не тронуты.

**Прозрачность задаёт карта, а не файл.** В самом файле группа непрозрачная,
`opacity="0.07"` стоит на `<image>` в `ReportingHexMap.tsx`. Если гасить каждый
район по отдельности, на общих границах прозрачность складывается и проступает
сетка швов; при непрозрачной группе внутри изображение сначала собирается
целиком, и только потом гаснет.

## Исходник не удалять

`kurgan-oblast-outline.svg` в интерфейсе больше не используется, но остаётся
в репозитории: это вход для этого сценария. Если понадобится другой вариант
подложки — например с районными границами линиями, а не заливкой, — брать
надо оттуда.

## Что ещё убрано из карты той же правкой

Помимо подложки, из `ReportingHexMap.tsx` сняты диагональный градиент
`#26345e → #11182e` с его `<rect>`, декоративная белая клякса (`opacity 0.055`),
пунктирная дуга (`opacity 0.14`) и тень у сот. Фон теперь рисует контейнер
одним ровным `#10162b`.

Тень (`feDropShadow` в фильтре с областью `-40 %…180 %`) — это «чтобы они
не были в квадратике»: область фильтра прямоугольная, и мягкое тёмное пятно
внутри неё на светлых участках фона читалось углами. На ровном фоне соту
достаточно отделяет собственная рамка.

После правки в SVG карты остаются только `<image>` подложки, 37 сот
и подписи к ним — ни `<defs>`, ни фильтров, ни градиентов.
